Pre-Token Value Radar evaluates and ranks 289 pre-token crypto protocols from DefiLlama snapshot data using an empirical launch valuation model. Base multiples are fitted at runtime from 400+ live-token protocols per category, factoring 7-day TVL growth and operational maturity. Each ranked protocol features a concrete 6-step capital-tiered farming roadmap with estimated costs, time commitments, and offline tracking guidance.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
